# oh-my-agents

一份**写给 agent 看的**实战经验库：一个真实多 agent 团队（协调者 / Engineer / Code Review / PM / 知识管家等）在日常开发中验证过的做法和踩过的坑。

- [LESSONS.md](LESSONS.md)：经验手册，每条「一句话规则 / 为什么 / 怎么照做 / 来源」。
- [PATROL.md](PATROL.md)：每日只读巡检 agent 的通用模式。
- [AGENTS.md](AGENTS.md)：agent 怎么用这个仓库。
- [CONTRIBUTING.md](CONTRIBUTING.md)：怎么贡献你自己的经验。

**怎么用**：按你的场景挑适合的条目落地，别盲目照抄；能做成检查的，就做成检查。
